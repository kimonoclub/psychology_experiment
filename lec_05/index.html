1. 心理学の2大潮流：実験的アプローチと個人差アプローチ

心理学が人間の心や行動を科学的に探究する際、研究の進め方には大きく分けて2つの強力なアプローチが存在します。第1回の演習で扱った「視覚刺激と聴覚刺激による反応時間の比較（リアクションバー課題）」のように、実験者が人為的に条件を操作し、その効果を厳密に比べる手法を「実験的アプローチ（条件統制）」と呼びます。

これに対して、参加者が生まれつき持っている属性や、日々の生活習慣によって生じている状態（睡眠時間、日中の眠気、性格、不安傾向など）を測定し、そのばらつきと行動との関連を調べる手法を「個人差アプローチ（指標による群分け・相関研究）」と呼びます。

研究アプローチ 主たる関心・目的 研究の手法・特徴 強みと留意点
実験的アプローチ
（条件統制）		 人間に共通する一般的・普遍的な認知・行動の法則の解明。 独立変数を人為的に操作。無作為割り付けや反復測定で条件以外のノイズを均一化。 時間的順序が担保され、強い因果関係を主張できる。
個人差アプローチ
（相関・群分け）		 個人の多様性（人によってなぜ反応や行動が異なるのか）の解明。 質問紙得点や生活記録による群分け、連続数値間の相関分析。 自然な生活習慣を捉える現実的妥当性があるが、因果関係は直接証明できない。

2. 相関関係と因果関係の混同：「第3の変数（交絡因子）」の罠

個人差アプローチにおける典型的な落とし穴が、「相関関係と因果関係の混同」です。例えば、「日常の睡眠時間が短い人（夜更かししている人）ほど、リアクションバーを掴む反応時間が遅い（負の相関）」という測定結果が得られたとします。このデータを見て、直ちに「睡眠不足が原因となって、脳の反応速度が低下した」と断定することは科学的に誤りです。

⚠️ 潜んでいる「第3の変数（交絡因子）」の例

両方の変数に同時に影響を及ぼしている背後の要因として、「実験へのモチベーションの低さ」や「日常的な生活の乱れ・体調不良」が潜んでいる可能性があります。

モチベーションが低い学生は、「夜遅くまで遊んで睡眠時間が短くなる」と同時に、「翌日の実験に対しても集中せず、身が入らないために棒を掴むのが遅くなった」のかもしれません。

【第3の交絡因子：モチベーション低下】
$\swarrow$           $\searrow$
夜更かし（睡眠時間短縮）    実験への不集中（反応遅延）
※睡眠時間と反応時間の間は見かけの相関（擬似相関）にすぎない可能性

見かけ上はきれいな相関関係が存在していても、真の原因は背後にある交絡因子であり、2つの変数の間に直接的な因果の糸が存在しないケースを排除しきれないのが、個人差アプローチを扱う際の決定的な注意点となります。

3. なぜ人は眠るのか：睡眠がもたらす心身の回復と記憶の定着

個人差による相関の限界を超えて、睡眠そのものが私たちの脳や身体にどのような生理的・認知的効果をもたらしているのかを実験的に検証した研究を見てみましょう。

📖 単語ペア記憶実験と「レミニセンス現象」

無関連な単語ペア（例：「自転車―クジラ」46組）の学習直後のテスト1（平均37組正答）の後、十分な睡眠をとらせて翌朝にテスト2を実施したところ、正答数は「41組」へと有意に向上しました。

睡眠を挟むことで忘却ではなく記憶成績が向上するこの現象を「レミニセンス現象」と呼びます。睡眠は単なる活動の停止ではなく、脳が昼間に取り込んだ情報を整理・統合し、長期記憶として固定化するための積極的な作業時間です。

■ ノンレム睡眠（特にステージ3・4の徐波睡眠） 脳波の活動が低下する深い眠り。成長ホルモンの分泌が促され、傷ついた筋肉や身体組織、免疫系の修復・回復が精力的に行われる。
■ レム睡眠（急速眼球運動睡眠） 筋肉は脱力しているが脳は活発に活動。昼間に経験したエピソードや感情の記憶が再生され、既存の知識ネットワークと結びつく情報の整理・統合が行われる。

🎾 アスリートを対象とした睡眠介入研究

普段通りの睡眠期間（1週間）と、毎晩9時間の睡眠を確保させた介入期間（1週間）を比較した実験では、9時間睡眠をとった期間において日中の主観的眠気が大幅に減少しただけでなく、サーブの打球精度が約9%も向上することが実証されました。十分な睡眠は心身の回復のみならず、運動スキルの正確性や認知的判断力を飛躍させる必須条件です。

4. 科学の健全性を守る作法：pハッキングの排除と事前登録（SAP）

心理学が客観的な科学としての信頼性を保つためには、得られたデータをどのように分析し、どのように結論づけるかという倫理的基準が極めて重要となります。

🚫 戒められるべき不正：「pハッキング（p-hacking）」

研究者が「有意差（$p < .05$）を出したい」という誘惑に駆られ、データを集めた後に都合よく操作してしまう行為の総称です。

  • 有意になるまで外れ値の除外基準を何度も弄り回す。
  • ピアソンの積率相関で有意にならなかったため、事後的にスピアマンの順位相関へ切り替える。
  • 結果を見てから「最初からこの結果を予測していた」と後付けで仮説を書き換える（HARKing）。

📋 統計分析計画書（SAP：Statistical Analysis Plan）と事前登録

不正や無意識のバイアスを完全に防ぐための標準作法が「事前登録（Pre-registration）」です。データを収集する前（または開封前）に、仮説、外れ値の除外基準、正規性の有無に応じた統計手法を詳細に文書化して確定させます。

あらかじめ分析のルールを固定し「鍵をかけておく」ことで、分析者の都合による恣意的なデータ操作を排除し、誠実で透明性の高い科学的結論を導くことができます。

【第1問】心理学の研究手法における「実験的アプローチ（条件統制）」の特徴として、最も適切なものを一つ選びなさい。

【第2問】「睡眠時間が短い学生ほど、反応時間が遅い」という相関関係が得られた際、それを直ちに「睡眠不足が反応速度を低下させた」と断定できない理由として、最も適切なものはどれですか。

【第3問】単語ペア記憶実験において、学習直後のテスト1よりも、十分な睡眠をとった後のテスト2の方が記憶成績が向上した現象の名称として、正しいものはどれですか。

【第4問】睡眠の周期構造において、成長ホルモンの分泌が促され、傷ついた筋肉や心身の組織の修復が主に行われる段階として、最も適切なものはどれですか。

【第5問】アスリートを対象に「毎晩9時間睡眠」を1週間確保させた睡眠介入研究において、観察された客観的なパフォーマンスの変化として正しいものはどれですか。

【第6問】統計分析計画（SAP）に基づき2つの連続変数の相関分析を行う際、双方の変数に正規性が確認された場合に適用すべきパラメトリックな統計手法はどれですか。

【第7問】データ取得後に、$p < .05$（有意差）が出るまで外れ値の除外基準を都合よく変えたり、検定手法を恣意的に切り替えたりする不適切なデータ操作行為を何と呼びますか。

【第8問】研究の透明性と再現性を確保するため、データを集めて開封する前に仮説や外れ値基準、統計手法を確定させて文書化しておく設計書の名称として、正しいものはどれですか。
